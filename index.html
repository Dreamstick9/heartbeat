      How it works

      Put the task ID in your PR title, like KL-07: register route. An open PR marks it in review; a merged PR marks it done.

      Tasks with nothing to merge, like testing, notes or rehearsal, have a Mark done button. Marks are saved in this browser only, so each person ticks their own.
